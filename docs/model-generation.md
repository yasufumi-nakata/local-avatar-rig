# アバター画像の生成・取込ガイド

本プロジェクトは、Neutral / Blink / Mouth-openの3枚を同一キャンバスに位置合わせした
軽量Web表情リグを扱います。生成フォームはプロンプトを作る機能であり、画像生成サービスへ
接続する機能ではありません。利用者が選んだツールで画像を生成し、完成したPNGを取り込みます。

## 生成するもの

- Neutral: 目を開き、口を軽く閉じた正面の基準画像です。
- Blink: 基準画像から両まぶたの周辺だけを変えた閉眼状態です。
- Mouth-open: 基準画像から口の周辺だけを変えた発話状態です。
- 背景: 必要な場合だけ、別のPNGを利用者が持ち込めます。

この手順で階層化された制作データ、専用SDK向けモデル、パーツ別の描き足し、デフォーマ、
物理設定が自動生成されるわけではありません。多層のモデルが必要な場合は、髪、顔、
目、口、胴体、衣装を分離し、回転時に見える部分も制作してください。

## 推奨ワークフロー

1. 「モデル生成」でキャラクターの役割、配色、衣装、モチーフ、除外事項を定義します。
2. Neutralのプロンプトを生成ツールへ渡し、正面の基準画像を作ります。
3. 髪や肩の欠け、顔の遮蔽、手、文字、透かし、描かれた市松背景がないか確認します。
4. 採用したNeutralだけを編集元にしてBlinkを作ります。
5. 同じNeutralからMouth-openを作ります。
6. 3枚を取込検証に入れ、同寸法と実際の透明アルファを確認します。
7. 重ね合わせで髪、衣装、肩、顔の輪郭が動かないか確認します。
8. 明るい背景と暗い背景で透明な縁を確認します。
9. 生成ツール、生成日、参照元、プロンプト、SHA-256をManifestに記録します。
10. プレビューに適用し、必要に応じて目と口のパッチ位置を調整します。

## 画像の条件

キャラクターの3状態は16:9、推奨1672×941です。各PNGは20MB以下、1画像あたり
1,000万画素以下で、端末のWebGLテクスチャ上限に収めます。3状態は同寸法で、
画像の外側に実際の透明画素が必要です。背景PNGは不透明でも構いません。

Neutralは中央に配置した正面姿勢にし、髪全体、首、胴体、両肩を含めます。手は画面外に置き、
目と口を髪や小物で隠さないでください。文字、ロゴ、透かし、背景はキャラクター画像に含めません。

差分生成では「同じキャラクター」と指定するだけでなく、編集対象を目または口に限定します。
キャンバス、切抜き位置、輪郭、頭の角度、顔の形、髪、衣装、肩の姿勢、照明、色、線を
保持するよう指定してください。再生成のたびに画像を実見し、位置合わせを確認します。

## 組込みアバター

Default Navigatorは、銀青の髪と研究服を持つAI生成のキャラクターです。組込み画像は3点で、
すべて1672×941のRGBA PNGです。採用Neutralを基準に、BlinkとMouth-openの必要なRGBだけを
目または口の局所領域へ合成し、出力のアルファ値をNeutralから保持しています。

ファイルとハッシュは[`default-navigator-v1.manifest.json`](../public/assets/default-navigator-v1.manifest.json)、
構成と検証方法は[設計記録](design/default-navigator-v1.md)をご覧ください。
Manifestに掲載する生成用ブリーフは公開用に再構成したもので、当時の入力の逐語記録では
ありません。AI生成は再実行時の同一出力を保証しないため、確定画像の識別にはSHA-256を使います。

Neutralに含まれるC2PAメタデータの存在と内容を記録していますが、署名はローカル検証して
いません。Canvasで合成した差分には元のメタデータが保持されないことがあります。
メタデータやハッシュは権利許諾を証明するものではありません。
