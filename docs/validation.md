# 公開版の検証手順・合格基準

最終更新: 2026-09-10（Asia/Tokyo）

この文書はLocal Avatar Rigの公開版を検証する手順です。以下の項目は合格基準であり、
記載だけで実行済みとは扱いません。対象の版、実行環境、結果は末尾の記録欄へ残します。

## 自動検証

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm exec playwright install chromium
pnpm test:browser
LOCAL_AVATAR_RIG_TEST_BUILD=1 pnpm test:browser
pnpm security:audit
git diff --check
```

`pnpm check`は組込み資産の検査、ユニットテスト、型検査、production buildを実行します。
ブラウザテストは専用のローカルサーバーを起動します。開発サーバーのソースを直接読み込む
描画・物理のテストは、`LOCAL_AVATAR_RIG_TEST_BUILD=1`のビルド版実行では対象外として
スキップします。スキップ件数を含めて結果を記録し、両方の実行を必要とします。
依存パッケージとブラウザのインストール、脆弱性データベースの照会にはネットワーク接続が
必要です。

合格基準は次のとおりです。

- 組込みPNGが3点、アバターが`default-navigator-v1`の1種類です。
- 画像の寸法、RGBA形式、ファイルサイズ、SHA-256がManifestと一致します。
- 3状態のアルファ輪郭が一致し、目または口の局所領域外に差分がありません。
- 生成用プロンプト、持込条件、姿勢の符号と数値範囲のテストが通ります。
- 本番の頂点シェーダーをGPUで実行し、顔の比率、首の長さ、襟・肩・胸の固定、
  複合回転での三角形の非反転を確認できます。
- 10〜240fpsで物理の進行量が一致し、長い停止のあとも計算量が制限されます。
- 画像からのボーン推定が、差分のない画像・位置ずれ・胴体欠落を確度低として扱います。
- 組込みアバターごとの顔パッチ・関節の調整が再読み込み後も残り、壊れた値は分離されます。
- 顔追従の短い検出ロストで姿勢を保持し、継続ロストで正面へ戻ります。
- 顔追従モデルの取得先と整合性検査、許可外通信の拒否がテストで確認できます。
- 型検査とビルドが成功し、依存物の監査結果を確認できています。
- ソース管理対象とビルド成果物にFace Landmarkerの`.task`ファイルがありません。

監査に指摘がある場合は内容と対応を記録し、未解決の指摘を「問題なし」と表現しません。

## ブラウザの表示・操作

デスクトップ1536×1024とモバイル390×844で次を確認します。

- 初期表示でカメラ・マイクの許可要求が出ません。
- WebGLが準備完了となり、アバターが表示されます。
- プリセットとスライダーが対応する姿勢・表情を動かします。
- 背景切替、持込画像の適用、標準アバターへの復帰が動作します。
- PNG保存に現在のアバターと選択背景が含まれます。
- 生成フォームのコピー、プロンプト保存、Manifest保存が動作します。
- 取込PNGの不正な署名、容量超過、過大寸法、透明度や寸法の不一致を拒否します。
- 取込3枚の検査後にボーンを推定し、確度と根拠を表示します。
- 関節をドラッグまたはスライダーで動かしても、首の上下や肩と胸の順序が逆転しません。
- 首振り、うなずき、傾きで襟、肩、胸が引っ張られず、髪が反転しません。
- 持込画像の一時URLが適用中は保持され、不要になった時点で解放されます。
- 横スクロールや文字・ボタンの重なりがなく、主要操作に到達できます。
- 自動モーション停止と`prefers-reduced-motion`の設定が反映されます。
- アプリ由来の未処理例外や警告がありません。

## 通信・入力機器

手動表示と顔追従開始後を分けて確認します。

| 操作 | 合格基準 |
| --- | --- |
| 初期表示・手動操作 | アプリの配信元以外への要求がありません。 |
| 顔追従の明示開始 | モデル取得先が固定URLのみで、フレームを送信しません。 |
| モデル取得の失敗・内容不一致 | 推論を開始せず、失敗を表示して入力資源を解放します。 |
| 許可外のWorker要求 | 実際の外部通信になりません。 |
| カメラ・マイク停止 | トラックが終了し、使用中表示が消えます。 |
| 開始途中の停止・再開始 | 古い要求で入力が復活せず、二重開始になりません。 |

通信先の確認は、モデルの取得による外部通信と、画像・音声の外部送信を区別します。
顔追従を開始した試験に「外部通信0件」を一律の基準として使いません。
実カメラ・実マイクの結果は、疑似入力やモックによるテストと別に記録します。

実機での顔追従は、左右移動、Yaw、Pitch、Roll、片目ずつの閉眼、口の大小を確認します。
一瞬の検出ロストで首が跳ね戻らないこと、顔を外し続けたときのNeutral復帰、停止・再開に
よる再較正、カメラ切替、権限拒否後の再試行も確認します。
マイクは小声、通常の声、無音で口開きが変化し、顔の口開きと併用できるか確認します。

## スクリーンショット

ローカルサーバーを起動し、別のターミナルで撮影します。

```bash
pnpm exec vite --host 127.0.0.1 --port 4173 --strictPort
```

```bash
LOCAL_AVATAR_RIG_CAPTURE_URL=http://127.0.0.1:4173 pnpm capture:default
```

固定5状態の撮影条件と見る点は[モーション確認](motion-comparison.md)に記載しています。
撮影後は画像を開き、輪郭、目と口の境界、UIの文字、背景、表示名称を目視確認します。
静止画だけで連続動作や実機入力の合格を判定しません。

## 公開内容

公開対象のファイル、ファイル名、メタデータ、コミット履歴を確認します。秘密鍵、
認証情報、内部資料、録画、個人情報、利用許諾の確認できない同梱物がないこと、
必要なライセンスと帰属表示が揃っていることを確認します。

公開後は既定ブランチ、リポジトリの公開状態、ローカルとリモートのコミット一致、
CIの結果、READMEと画像の表示を確認します。
