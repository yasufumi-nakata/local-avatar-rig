# アーキテクチャ

Local Avatar RigはReact / Viteの単一ページアプリです。ブラウザでの2Dアバター描画、
手動操作、カメラによる顔追従、マイク音量による口パク、PNGの取込を扱います。
画像生成APIや配信サーバーには接続しません。

## 描画

`WebGLAvatar`が`WebGLAvatarRenderer`を管理し、48×30のUVメッシュをWebGL 1で描画します。
専用のアバターモデリングSDKを使わず、3状態のPNGと独自のメッシュ変形で表情を作ります。

1. Neutralを基準テクスチャとして読み込みます。
2. 頭、顔内部、胴体、前髪、横髪、後髪へ異なる変形の重みを適用します。
3. 60Hz固定ステップのばねで胴体と髪の遅れを更新します。
4. 視線は虹彩の周辺、Blinkは左右の目、Mouth-openは口の局所領域で合成します。
5. WebGLを利用できない場合はNeutral PNGを表示します。

組込みアバターは`default-navigator-v1`の1種類、画像は3点です。シーン背景はCSSの
グラデーションで描き、PNG保存時はCanvasで対応する背景を描きます。利用者が背景PNGを
持ち込んだ場合は、その画像をシーン背景に使います。

## 入力の統合

顔の状態は次の`FaceRigPose`へ統一します。

```text
x / y / yaw / pitch / roll / scale
eyeX / eyeY
blinkLeft / blinkRight
mouthOpen / smile
```

- 手動操作はReact stateをRefへ反映します。
- 顔追従はWorker出力を平滑化し、毎フレームのReact再描画を挟まずRefを更新します。
- マイクはRMSから作る`audioLevel`と`speaking`を渡し、顔の口開きと大きい側を使います。
- ポインター追従はリグ全体への小さなCSS平行移動です。

## 顔追従Worker

顔追従の開始操作後にカメラの利用許可を要求し、Workerを初期化します。WASMとローダーは
アプリのビルドに含め、同一オリジンから読み込みます。Face Landmarkerのモデルファイルは
リポジトリにもビルド成果物にも含めません。Workerが提供元の固定URLから取得し、
3,758,596 bytesとSHA-256の両方が一致した場合だけ初期化に使います。
固定URLとハッシュは[モデル取得条件](../src/assets/models/README.md)に記載しています。

モデル取得は認証情報とRefererを送らず、リダイレクトを拒否します。Workerの外部`fetch`は
この固定モデル取得だけを許可し、その他を遮断します。CSPにも接続先の制限を設定します。
通信の範囲と提供元へ伝わり得る情報は[プライバシー文書](privacy.md)をご覧ください。

推論にはカメラフレームを`ImageBitmap`として約24fps以下で1枚ずつWorkerへ転送します。
処理中に次のフレームを積み上げず、処理後に画像を解放します。顔のランドマーク、52種の
blendshape、変換行列を姿勢と表情へ変換し、最初に検出した顔を正面基準に較正します。
顔が消えるとNeutralへ戻り、1.5秒を超えて消失した場合は次の顔で再較正します。
鏡像表示に合わせた姿勢の符号と数値範囲は純粋関数としてテストします。

## 画像の生成補助と取込

生成フォームはプロンプトを端末内で組み立てます。実際の画像生成は利用者が選んだ
外部ツールで行います。PNG取込では復号前に署名、容量、IHDR寸法、画素数、
WebGLテクスチャ上限を検査し、復号後に透明画素、状態間の寸法、SHA-256を検査します。
取込画像は一時的な`blob:` URLで表示し、リポジトリへ自動追加しません。

## 保存と終了処理

`localStorage`に保存するのは表示設定、組込みアバターのIDと顔パッチ位置、選択カメラの
`deviceId`です。カメラフレーム、音声、顔の数値、持込画像、プロンプトを自動保存しません。
PNG、Manifest、プロンプトは利用者が保存ボタンを押した場合にダウンロードします。
入力停止やページ破棄ではメディアトラック、Worker、音声処理、一時画像URLを解放します。

## ビルドと配布

ビルドにはアプリ、Worker、WASM、組込みの3画像が含まれます。外部スクリプト、外部画像、
object/embedをCSPで制限し、WASM実行のため`wasm-unsafe-eval`を指定しています。
コードはMIT、組込みアートと画面画像は[別の利用条件](../ASSET_LICENSE.md)です。
依存物の告知とライセンスは[第三者ライセンス一覧](../THIRD_PARTY_NOTICES.md)にあります。
Viteの開発・プレビューはWorkerを含む応答にCSPを設定します。本番ホストは`_headers`の
設定に対応させるか、同等のHTTPヘッダーを設定してください。ページのmeta CSPだけでは
別ファイルのWorkerの通信制限を代替できません。
